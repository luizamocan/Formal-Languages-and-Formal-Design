IDENTIFIER — Regular Grammar
Start symbol: Q0

Q0 -> LETTER Q1
Q1 -> LETTER Q1 | DIGIT Q1 | UNDERSCORE Q1 | ε

NUMBER — Regular Grammar
Start symbol: N0

N0 -> ZERO NZERO | NONZERO_DIGIT NINT
NINT -> DIGIT NINT | DOT NDOT | ε
NDOT -> DIGIT NFRAC
NFRAC -> DIGIT NFRAC | ε
NZERO -> ε

STRING — Regular Grammar
Start symbol: S0

S0 -> QUOTE S1
S1 -> QUOTE S2 | STRING_CHAR S1
S2 -> ε
